# EL ESPEJO DEL ARTISTA
## Objetivo
Proyecto basado en la creación de un sistema inteligente relacionado con el arte el cual tiene como objetivo ayudar al artista a mejorar sus obras artisticas mediante el analisis de imagenes y retroalimentacion de una IA para obtener conocimiento y darle procesos de mejora al usuario.

## Tecnologias
### FrontEnd
| Nombre | Proposito |
|:------:|:---------:|
|React| Construcción de interfaces mediante componentes.|
|TypeScript| Tipado estático para mejorar la seguridad y mantenibilidad del código.|
|Tailwind CSS| Diseño y estilizado de la interfaz de usuario (UI).|
|Vite| Servidor de desarrollo local y herramienta de compilación para producción.|

### BackEnd
| Nombre | Proposito |
|:------:|:---------:|
|Python| Llenguaje de programación del backend.|
|FastAPI| Framework para desarrollar la API REST.|
|PostgreSQL| Sistema gestor de bases de datos relacional.|
