# Instalacion
Verificar que este la versión de node 24.22.1, con:
```shell
node -v
```

Ejemplo de salida:
```shell
v24.22.1
```

Una vez confirmando que contamos con la versión de node requerida dentro de la carpeta frontend debemos ejecutar el siguiente comando:
```shell
npm install
```

# Levantar el frontend
Dentro de nuestra carpeta de frontend debemos ejecutar el siguiente comando:
```shell
npm run dev
```
